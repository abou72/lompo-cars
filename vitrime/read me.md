# 🚗 Lompocars Export — Guide d'utilisation

## 🔐 Accès admin

1. Ouvrir le site
2. Dans le menu de gauche, cliquer sur **🔒 Admin**
3. Entrer le mot de passe : `lompocars2025`

## ➕ Ajouter une voiture

1. Aller dans **🔒 Admin → onglet 🚗 Voitures**
2. Ouvrir **"➕ Ajouter une voiture"**
3. Remplir :
   - Marque, Modèle, Année
   - Prix USD et Prix FCFA
   - Kilométrage
   - État (Neuf / Occasion)
   - Description
   - **Photos** (plusieurs possibles, la 1ère est la principale)
4. Cliquer **💾 Enregistrer**

## ✏️ Modifier / Vendre une voiture

1. Descendre dans la liste des voitures
2. Cliquer sur la voiture
3. Changer le statut en **Vendu** (elle reste visible avec un badge VENDU)
   ou modifier les infos
4. Cliquer **💾 Mettre à jour**

## 🗑️ Supprimer une voiture

Même chose, bouton **🗑️ Supprimer**.

## 📩 Voir les messages reçus

Onglet **📩 Messages reçus** dans l'Admin.
